# よいまつり横丁 第2章 月見座（つきみざ）

十五夜に、大台をまわせ。

妖怪の住む夜の町「よいまつり横丁」の、六十年閉まっていたパチンコ屋「月見座」が舞台のブラウザゲームです。『ヤチンスピン』（第1章）のつづき。玉を打つ前に、盤の釘の場所へ役物（やくもの）をひとつずつ置いて、自分だけの盤を育てます。育てるほど点が跳ねて、大当たりが出ます。

**遊ぶ** → https://m0ch4771.github.io/tsukimiza/

## あらすじ

九月。ハナばあちゃんから、十七の夏に持ち帰ってしまった月見座の銀の玉を「返してきて」と頼まれる。月見座の大台は、玉がひとつ欠けると回らない。大台が回らなければ満月はのぼらず、満月の晩にしか見えない横丁への道も、大人には見えない。十五夜まで五晩。横丁じゅうの縁を集めて大台を回し、ばあちゃんを満月の横丁へ呼ぶ。

## 遊びかた

- 1手番：役物を3つから1つえらぶ → 盤の好きな釘に置く（役物の上に置くと置きかえ）→ 盤をさわって落とす位置を決め、指をはなして玉を打つ
- 点 ＝ 文 × 倍率 × 入賞口の倍率。役物は何回当たっても全部効く
- 手玉5つで目標の縁をこえれば勝ち。ひと晩は 宵 → 夜ふけ → 真夜中。真夜中には横丁のだれかの「できごと」がある
- 縁が足りなければ、最初の晩からやりなおし
- 最終話をクリアするとエンドレス。記録は 𝕏 にポストして #よいまつり横丁 #月見座 でくらべられる

スマホの縦画面向けです。進み具合はブラウザに保存され、タイトルの「つづきから」で、やめたところ（手番のはじめ・屋台）から再開できます。

## 遊べるもの

- ストーリー：序章＋全5話＋エピローグ。挿絵12枚（見た挿絵はタイトルの「挿絵」で見返せる）
- 役物14種（ふつう・めずらしい・とくべつ）、真夜中のできごと5種
- 登場人物12人（新キャラ：ギンコ・テツ・ウヅキ・アオ）

## ファイル

```
index.html        組み立て済みのゲーム本体（art/・bg/・cg/ と同じ場所に置く）
src/ui.html       画面・見た目のひな形
src/engine.js     ルール（盤・玉の動き・役物・目標）
src/story.js      台本・登場人物・背景・挿絵の置き場所
src/main.js       画面の動き・会話・屋台
art/face/         顔窓（12人×4表情。n=通常 s=笑顔 o=驚き x=その人の顔）
art/sheet.png     役物などのドット絵シート（32×32、16列）
art/sheet.json    シート内の並び
bg/               会話の背景（11枚）
cg/               挿絵（12枚）
tools/build.py    src/ と art/ から index.html を組み立てる
tools/sim.js      難しさをボットで調べる
tools/value.js    役物ごとの強さをくらべる
```

## なおしたあと

`src/` を書きかえたら、組み立てなおします。

```
python3 tools/build.py
```

難しさを調べるときは（Node.js が必要）：

```
node tools/sim.js 500 smart
```
